# EV_PNC_docs

Platform documentation for the e-Devlet integrated EV roaming consent and eMSP layer:
architecture, ADRs, RFP, corridor-pilot and go/no-go specs, KVKK/PCI notes, and the squad
working agreement. Consent and hub-vendor documents live in their own repositories.

## Contributing

PR titles follow conventional commits, `type(scope): subject` with an optional scope, such as
`docs: ...` or `docs(adr): ...`; the title becomes the squash commit on `main`. Every PR that is
ready for review is checked by the CI review agent (`review / verdict`); drafts are not reviewed.
